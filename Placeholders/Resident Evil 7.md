# Placeholders
|Placeholder|Function|
|--|--|
|{state}|Shows the current configuration section: Main Story, DLC Story, or DLC Minigame|
|{mode}|Shows the current mode, e.g. "Main Story", "Not a Hero", "End of Zoe", etc.|
|{gamemode}|Shows the current game mode|
|{character}|Shows the name of the character you are playing|
|{characterid}|Shows the ID of the current character|
|{difficulty}|Shows the current difficulty|
|{difficultyid}|Shows the ID of the current difficulty, when available|
|{health}|Shows your current health|
|{maxhealth}|Shows your current max health|
|{healthstatus}|Shows your current health status|
|{healthpercentage}|Shows your current health as a percentage value|
|{healthstatusemoji}|Shows your current health status as an emoji|
|{location}|Shows the current map area and floor|
|{area}|Shows the current area|
|{region}|Shows the current area|
|{room}|Shows the current floor, when available|
|{roomid}|Shows the text ID of the current map title, when available|
|{mapid}|Shows the ID of the current map, when available|
|{objective}|Shows the current active objective|
|{primaryobjective}|Shows the primary objective in the current objective hierarchy|
|{secondaryobjective}|Shows the secondary objective in the current objective hierarchy|
|{objectivepath}|Shows the current objective hierarchy, separated by /|
|{objectives}|Shows the active objectives, when available|
|{objectiveid}|Shows the ID of the current objective, when available|
|{primaryobjectiveid}|Shows the ID of the primary objective, when available|
|{secondaryobjectiveid}|Shows the ID of the secondary objective, when available|
|{weapon}|Shows your current equipped weapon, when available|
|{currentweapon}|Shows your current equipped weapon, when available|
|{weaponid}|Shows the ID of your equipped weapon, when available|
|{ammo}|Shows the loaded ammo of the equipped weapon, when available|
|{loadedammo}|Shows the loaded ammo of the equipped weapon, when available|
|{reserveammo}|Shows your reserve ammo, or ∞ when infinite ammo is enabled|
|{infiniteammo}|Shows whether infinite reserve ammo is enabled, when available|
