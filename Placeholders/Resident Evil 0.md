# Placeholders
|Placeholder|Function|
|--|--|
|{state}|Shows the current game state|
|{character}|Shows the name of the character you are controlling|
|{characterid}|Shows the ID of the current character|
|{difficulty}|Shows the current difficulty|
|{difficultyid}|Shows the ID of the current difficulty|
|{location}|Shows the current region, floor and room when available|
|{area}|Shows the current region|
|{region}|Shows the current region|
|{floor}|Shows the current floor|
|{room}|Shows the current room when available|
|{roomid}|Shows the ID of the current room|
|{weapon}|Shows your equipped weapon|
|{currentweapon}|Shows your equipped weapon|
|{weaponid}|Shows the ID of your equipped weapon|
|{weaponammo}|Shows your equipped weapon and available ammunition|
|{ammo}|Shows loaded ammunition, or ∞ for infinite ammunition|
|{loadedammo}|Shows loaded ammunition, when available|
|{reserveammo}|Shows reserve ammunition, or ∞ for infinite ammunition|
|{infiniteammo}|Shows whether infinite ammunition is enabled|
