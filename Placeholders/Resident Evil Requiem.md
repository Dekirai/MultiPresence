# Placeholders
|Placeholder|Function|
|--|--|
|{character}|Shows the name of the character you are playing|
|{characterid}|Shows the ID of the current character|
|{health}|Shows your current health|
|{maxhealth}|Shows your current max health|
|{healthpercentage}|Shows your current health as percentage value|
|{location}|Shows the current region and room|
|{region}|Shows the current region|
|{room}|Shows the current room|
|{mapsectionid}|Shows the ID of the current map section|
|{mapfloorid}|Shows the ID of the current map floor|
|{scenename}|Shows the name of the current scene|
|{placeid}|Shows the ID of the current map section|
|{currentweapon}|Shows your current equipped weapon|
|{weapon}|Shows your current equipped weapon|
|{weaponid}|Shows the ID of your equipped weapon|
|{itemid}|Shows the inventory item ID of your equipped weapon|
|{ammo}|Shows the current ammo of the equipped weapon|
|{reserveammo}|Shows the amount of reserve ammo for the equipped weapon|
|{difficulty}|Shows the current difficulty|
|{difficultyid}|Shows the ID of the current difficulty|
|{money}|Shows your current credits when playing Leon|
|{moneydisplay}|Shows Credits followed by your current money when playing Leon|
|{objective}|Shows the current objective|
|{objectivecount}|Shows your current objective progress|
|{objectivemaxcount}|Shows the amount required to complete the current objective|
|{objectiveguid}|Shows the text ID of the current objective|
|{state}|Shows the current game state|
