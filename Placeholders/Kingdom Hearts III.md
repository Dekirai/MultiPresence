# Placeholders

|--|--|--|
|{level}|Shows your current level|In World|
|{gummilevel}|Shows your current Gummi level|In Gummi|
|{room}|Shows the current map and area|Everywhere|
|{location}|Shows the current map and area|Everywhere|
|{map}|Shows the current map|Everywhere|
|{area}|Shows the current area|Everywhere|
|{subarea}|Shows the current subarea|Everywhere|
|{world}|Shows the current world|Everywhere|
|{hp}|Shows your current HP|In World|
|{mp}|Shows your current MP|In World|
|{difficulty}|Shows the current difficulty|Everywhere|
|{world_icon_name}|Icon name of the current world, to be used with Large/Smallasset|Everywhere|
|{worldid}|Shows the ID of the current world|Everywhere|
|{mapid}|Shows the ID of the current map|Everywhere|
|{areaid}|Shows the ID of the current area|Everywhere|
|{difficultyid}|Shows the ID of the current difficulty|Everywhere|
|{state}|Shows the current game state|Everywhere|
