# Placeholders
|Placeholder|Function|Usable in|
|--|--|--|
|{mode}|Shows Story, Case File or Lobby|Lobby, Story, CaseFile|
|{level}|Shows the account level|Lobby, Story, CaseFile|
|{session}|Shows Singleplayer or Multiplayer with the player count|Lobby, Story, CaseFile|
|{players}|Shows the player count when playing online or with other players|Lobby, Story, CaseFile|
|{playercount}|Shows the current player count|Lobby, Story, CaseFile|
|{maxplayers}|Shows the maximum player count|Lobby, Story, CaseFile|
|{chapter}|Shows the current chapter number|Story|
|{case}|Shows the current case map|CaseFile|
|{caseasset}|Shows the image key of the current case map|CaseFile|
|{difficulty}|Shows the case difficulty|CaseFile|
|{casetype}|Shows Normal, Rare or Hardcore|CaseFile|
|{mapsize}|Shows the case map size|CaseFile|
|{lives}|Shows the case starting lives|CaseFile|
|{objective}|Shows the current objective with its progress|Story, CaseFile|
|{progress}|Shows the current objective progress|Story, CaseFile|
|{map_icon}|Shows the current case image key or logo|Everywhere|
